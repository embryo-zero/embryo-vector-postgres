# Embryo Vector Postgres

Embryo Vector Postgres is Embryo-Zero's fork of [pgvector](https://github.com/pgvector/pgvector) (e9c5357, commit e9c5357). It does vector search inside Postgres.

- Our changes live on the `embryo` branch. The original license files (LICENSE) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
